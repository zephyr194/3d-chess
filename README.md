# 楚河战阵 · 3D 中国象棋 Demo

一个面向浏览器的低多边形卡通 3D 中国象棋概念验证。首版目标是验证“每一步棋像一次行军”的核心体验，同时保持标准象棋规则决定胜负。

## 当前能力

- 完整基础棋盘与 32 枚棋子
- 本地双人轮流对弈
- 车、马、炮、兵、象、士、将/帅的合法走子判断
- 将帅照面与自陷将军限制
- 选子、合法落点、吃子与胜负提示
- 卡通低多边形军种、可旋转缩放镜头
- 具象化山川、河流、关隘与行军道路棋盘
- 分兵种行军、炮击、接敌、受击与将军动画
- 浏览器实时合成的步伐、车轮、马蹄、炮击与碰撞音效
- 快速、标准、电影三档演出速度

## 本地运行

```bash
pnpm install
pnpm dev
```

## 验证

```bash
pnpm test
pnpm build
```
