# 楚河战阵 · 3D 中国象棋

低多边形卡通战场，标准中国象棋规则决定合法落点，实体道路决定行军演出。

- 格距 3.2，棋子维持 0.68；90 个站位等高，空棋位用小石钉与两端路数索引提示。
- 一片连续高度场形成平原、山峰、河谷、湖泊和溪流。土路、泥路、驰道与山路直接融入地形，避免叠加路面产生深度闪纹。
- 西侧渡船、中央城门拱桥、东侧贴壁栈道连接两岸；北岸木水寨与南岸石墙区分阵营。
- 城门、城墙、角楼、山林、营帐、物资、战旗与远处薄雾均为可旋转观察的原生 3D 场景。
- 七种军队模型用武器、头盔、坐骑区分，兵种文字印在身体或装备上。
- 选中不放大；悬停或长按合法目标，只预览一条实际行军道路。
- “看棋局”（M）显示真实棋局，支持点击、方向键和 Enter 走子，同步选子、合法目标、上一步和将军。
- 不同道路影响行进速度、步幅与声音；渡船上停止踏步和转轮，行军中底座不跳起。
- 战鼓实时合成，随过河、吃子和将军增强；音乐与音效独立开关，音量可调，后台停止鼓点调度。

## 运行

```bash
npm install --no-package-lock
npm run dev
```

仓库保留原有 pnpm 锁文件，使用 pnpm 时可用 `pnpm install --frozen-lockfile`。

## 验证

```bash
npm test
npm run build
```

`tests/battlefield.test.ts` 检查全部 90 个实际地面站位、道路图连通、人物足迹下的实际三角形支撑、渡船载人与复位，以及 10 回合真实棋局中的所有合法终点道路可达性。象棋引擎及原有规则测试保留。

浏览器截图与交互脚本：`scripts/capture-restored.py`。需要 Python Playwright 和 Chromium；默认连接本机 5173 端口。截图保存在 `screenshots/restored/`。该脚本只在浏览器响应中注入检查接口，不修改产品源码。

## 道路与氛围优化

道路采用不同的泥土颜色、路肩与齐地嵌石，桥头护岸和栈道斜撑加强实体衔接。渡船先空船靠岸，再接人过河，候船和乘船时停止踏步。改造前后同机位实机截图及道路、走子验证见 [验证说明](docs/road-refinement.md)。
