# 改造版恢复说明

2026-10-19：当前检出只有 `be6a6e5` 的旧版纹理棋盘，上一轮未提交的场景文件和截图未能找回。本次按已确认方案重新实现可运行改造版，不将旧版截图或生成概念图冒充改造结果。

## 实现位置

- `src/scene/board.ts`：稳定九路十排、统一地面高度、人物尺度与自适应镜头。
- `src/scene/landscape-layout.ts`：独立道路图、站位支路、三类过河通道、湖泊溪流、地形采样与按路面计时的行军路径。
- `src/scene/battlefield.ts`：连续山谷、嵌入地形的道路、真实桥面与甲板、城池水寨、山林营帐、远雾。
- `src/ui/tactical-board.ts`：直接读取主游戏状态的棋局图，鼠标、触屏与键盘操作。
- `src/game/battle-drums.ts`：由手势启动、随战况增强并在后台暂停的轻量合成配乐。
- `src/main.ts`：保留原象棋引擎，接入小型军队、装备文字、路线预览、不同路面行军与局部战斗反馈。

陆路地面和道路是同一高度场，避免两片重叠面出现闪纹；桥梁、渡船与栈道使用独立实体。站位地面 Y=0.54，棋子根节点 Y=0.545，选中时仍为 0.68。不存在用删除合法棋步或直线飞越地形作为寻路兜底。

## 验证范围

- `npm test`：12 项测试通过，包含原有 6 项象棋规则测试与新增 6 项场景测试。
- `npm run build`：TypeScript 和 Vite 构建通过，保留约 592 kB 主包提示。
- 所有道路按约 0.45 世界单位采样，对中心与半径 0.44 的八方足迹检查真实可见地形/桥面三角形支撑。
- 全部 90 站位的实际表面射线及九路十排对齐检查通过。
- 10 回合真实局势中的所有合法目标仍可通过独立路网到达。
- 浏览器验证及截图由 `scripts/capture-restored.py` 生成；结果见 `screenshots/restored/verification.json`。
- 桌面 1440×1024 和手机 390×844、DPR=1。实机画面为 Chromium WebGL 软件 GPU，未声称覆盖实体手机或硬件帧率。
